## 2. 与 v2 硬约束的冲突（**不要照抄**）

| 参考图里的做法 | 需求/实现约束 | 3D 里怎么处理 |
|---|---|---|
| 屋顶四周有较厚的木质/金属**凸起边框与角柱**（约 0.1 高） | 平屋顶顶面 30cm 内不得有阻断几何；边缘收边 ≤0.04（REQ-V2-BLD-03/REQ-V2-ART-01） | 保留视觉语言，但收边压到 ≤0.04 且不得阻断上方放置 |
| 三根金属短管**立在屋顶边缘/顶面上**（图 1/2/7） | 屋顶上不得有设备/管道；端口在**背面墙**（REQ-V2-BLD-03/06） | 端口贴后立面、低于屋面；屋面保持空 |
| 门前 2–3 级**台阶伸到占地外** | 模型外包络不得超出 3×3×1（REQ-V2-BLD-01） | 入口做**齐平门槛/内侧踏步**，不越界 |
| 图 7 最右（顶级）看起来是**倾斜玻璃顶** | 四档屋顶必须**平的、可叠放**（REQ-V2-BLD-03/04） | 顶级也用平屋面，只靠材质/构架/玻璃分区区分 |
| 图 8（施工阶段）**脚手架伸出占地、高于 1 格** | 施工阶段模型同样 ≤3×3×1（REQ-V2-ART-01/03） | 脚手架收进 3×3×1 内，或只做骨架剪影 |
| 剖面图室内层高明显 >1 格（海狸站直还有余量） | 建筑只有 1 格高；室内为抽象槽位（ADR-V2-001） | 只借“货架密度/暖光/水罐”的观感，不照搬层高 |
| 四栋**轮廓几乎相同**，主要靠材质区分 | 需求要求“轮廓/材质/开窗/端口至少两项不同” | 四档在**开窗模式/构架层次/端口数量**上再拉开差异 |

## 4. 标记规则（回答「每张图都要标记吗」）

* **不需要**在图片像素里加文字/箭头/编号：既会污染调色板与贴图取样，也会被图像模型画成假文字。
* 需要的“标记”用两层表达：
  1. **文件名**：`ref-<用途>-<可选阵营>.jpg`（见 §1）；
  2. **本清单**：文件 → 档位/用途 → 采纳点 → 冲突点。
* 如果要在聊天里区分，直接引用文件名即可；新增图按同一命名规则放进来并在 §1 加一行。
