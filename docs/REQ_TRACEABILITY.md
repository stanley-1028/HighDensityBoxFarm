Status vocabulary:

* **实现+自动验证** — code exists and an automated check proves it on this machine.
* **实现（待游戏内验证）** — code exists and compiles against the real game assemblies, but the
  behaviour needs a running game to confirm. This is the dominant status: the delivery machine has
  no working interactive game session (see VERIFICATION §13).
* **部分实现** — some requirements in the domain are delivered, others are documented gaps.
* **仅数据/契约** — delivered as data, contract or documentation, executed by another pipeline.
* **流程项** — a process gate for the release milestone, not a code artifact.

| D-2 | P1 applies the four constraint layers as **dispatch gates + growth channel**, not as a per-harvest multiplier on vanilla growth: shutdown/fallow/no-worker block dispatch; irrigation already controls vanilla growth via real soil moisture; dense mode adds real growth ×1.35; fatigue/maintenance/power multipliers are displayed and drive warnings, but making them slow vanilla `Growable` progress needs a private-API patch, which v0.1 does not take | requirement prefers 0 patches (REQ-IMPL-15); a speculative patch could not be verified here | ADR-004, docs/workstreams/farm-loop.md §8 |
| D-3 | Chapter-7 prerequisite chain is not enforced; only per-building `ScienceCost` gates the four tiers | 1.1.2.8 has no research nodes, no prerequisite spec and no tech tree (IL + official blueprint zip evidence); any other gate would be an unverifiable custom mechanism | ADR-007, docs/workstreams/tech-data.md §10.5 |
| D-4 | Dense-mode ×1.35 is realised as a growth-progress multiplier; fallow stops dispatch and applies daily fatigue recovery but vanilla growth continues | same zero-patch reason as D-2; growth is the only writable channel without patching yield code | docs/workstreams/farm-loop.md §8 |

## Round-14 update — ADR-009 patch in-game application (2026-10-25, VERIFICATION §20)

D-2's remaining gap ("fatigue/maintenance/power multipliers only displayed, not applied to vanilla
growth") is now **materially closed**: on a top-tier off-grid managed crop the single Postfix
rescaled `Growable` growth time from the vanilla 10 days to **50.63 days** with
`growthRate = 0.198 = G_irr 0.663 × G_power 0.60 × G_maint 0.50`, while `growthRate ≥ 0.999` stays a
no-op so healthy basic farms are unchanged. Status: CORE-03 / BAL-02 / BAL-28 = **实现+实机（托管格
四层乘算）**; residual evidence (non-managed crop regression, full-cycle harvest at the stretched
rate, save/reload non-stacking) is listed in VERIFICATION §20.2 and must close before release.
