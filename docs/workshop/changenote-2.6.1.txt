HDBF 2.6.1 - Crop selector stays usable while the colony runs / 作物选择器在游戏运行时保持可用

[EN] Player report: "the crop selector closes all the time" while the game is running, so a fixed crop could not be chosen - it only worked while the game was paused. Cause: the farm panel refreshes four times per second while the colony runs, and that refresh re-synced the crop dropdown even while its popup was open; touching the open vanilla dropdown closes it (the game only exposes a layout-lagged "popup visible" value, so the popup still counted as closed on the frame it opened). When paused the panel does not refresh, which is why it worked there. Fix: the panel now takes the exact open/closed state from the game's own dropdown open/close events and does not touch the popup while it is open - the periodic refresh and the item/value sync resume on the first tick after it closes, and switching to another building closes the popup cleanly. No Harmony, no reflection, no new dependencies, no save-schema change; UI only. Verified: 734 automated tests, validator OK, 44 release checks passed, plus a live A/B run: the popup stays open and a fixed crop can be selected while the game runs.

[ZH] 玩家回馈：游戏运行时「作物选择器的菜单一直自己消失」，选不了固定作物——只有暂停时才能选。原因：殖民地运行时农场面板每秒刷新 4 次，刷新会在作物下拉弹窗已经打开时仍然重新同步它；而触碰打开中的原版下拉就会把它关掉（游戏只提供一个滞后一轮布局的「弹窗是否可见」值，所以弹窗刚打开的那一帧仍被当成「已关闭」）。暂停时面板不刷新，所以暂停时正常。修复：面板改用游戏自带的弹窗打开/关闭事件取得精确状态，弹窗打开期间完全不触碰它——周期刷新与清单/取值同步都延后到它关闭后的第一个 tick；切换到别的建筑时也会干净地关掉弹窗。无 Harmony、无反射、无新增依赖、存档 schema 不变；只改 UI。验证：734 项自动测试、validator OK、44 项发布门禁通过；并做了实机 A/B：游戏运行时弹窗保持打开，且能成功选择固定作物。

[TW] 玩家回饋：遊戲運行時「作物選擇器的選單一直自己消失」，選不了固定作物——只有暫停時才能選。原因：殖民地運行時農場面板每秒刷新 4 次，刷新會在作物下拉彈窗已經打開時仍然重新同步它；而觸碰打開中的原版下拉就會把它關掉（遊戲只提供一個滯後一輪佈局的「彈窗是否可見」值，所以彈窗剛打開的那一幀仍被當成「已關閉」）。暫停時面板不刷新，所以暫停時正常。修復：面板改用遊戲自帶的彈窗開啟/關閉事件取得精確狀態，彈窗打開期間完全不觸碰它——週期刷新與清單/取值同步都延後到它關閉後的第一個 tick；切換到別的建築時也會乾淨地關掉彈窗。無 Harmony、無反射、無新增依賴、存檔 schema 不變；只改 UI。驗證：734 項自動測試、validator OK、44 項發布門禁通過；並做了實機 A/B：遊戲運行時彈窗保持打開，且能成功選擇固定作物。
